# PHASE A — CLOSE R04.4 QA

## A1. Garage Exit ทั้ง 6 หลัง

ทดสอบ Street Cub ออกจากอู่แต่ละหลังไปยังถนนบริการและถนนหลัก

โดยเฉพาะ G3 ที่ยังไม่ผ่าน:

- ตรวจตำแหน่ง Spawn
- ตรวจทิศทางรถ
- ตรวจ Garage Apron
- ตรวจ Waypoint Controller
- ตรวจ Collision
- ตรวจระยะเลี้ยวและความกว้างทางออก

**ห้ามสรุปว่า G3 มีสิ่งกีดขวางจากผล Waypoint Miss อย่างเดียว**

หากเป็นปัญหา Controller ให้แก้ Controller ทดสอบ หรือปรับวิธีวัด โดยไม่ทำให้รถในเกมผิดธรรมชาติ

ห้ามใช้ Teleport, Pivot หรือบังคับ Velocity เพื่อทำให้ผลการขับผ่าน

รายงาน G1–G6 แยกแต่ละหลัง พร้อมเวลาที่ใช้และเหตุผลเมื่อไม่ผ่าน

## A2. Full Roundtrip Version 10

ทดสอบบน Source และ Build ล่าสุดจริง:

Garage City → Zone 01 → Zone 02 → ... → Zone 12 → กลับ Garage City

ต้องใช้รถวิ่งจริงตลอดทาง ไม่ Teleport ข้ามโซน

ตรวจจุดทางเชื่อมที่เคยมีปัญหา X≈640 และ X≈1860 โดยใช้พิกัดจริงจาก Source ยืนยันอีกครั้ง

รายงาน:
- Build/Geometry Version
- ระยะเวลา
- Waypoint ผ่าน/ทั้งหมด
- จุดที่รถติดหรือหยุด
- Collision Trace หากมี
- ผลผ่านหรือไม่ผ่าน

ห้ามนำผล Version 9 มาอ้างเป็นผล Version 10

## A3. Cargo Regression

ทดสอบวงจรจริง:

1. Spawn ที่ Garage City
2. ขึ้น Street Cub
3. ขับไป Zone 01
4. ใช้ระบบ Pickup จริง
5. ตรวจ Cargo 0/1 → 1/1
6. ขับกลับ Garage City
7. ใช้ Deposit จริง
8. ตรวจ Cargo 1/1 → 0/1
9. ตรวจจำนวนฝากสำเร็จเพิ่มขึ้นตามระบบ Session จริง

ห้ามเพิ่ม Cargo ผ่าน Script ทดสอบเพื่อให้ผลผ่าน

หากยังไม่ผ่าน ต้องระบุขั้นตอนที่ล้มเหลวพร้อมหลักฐาน Server/Client

## A4. Grass / Shoulder / Road

ทดสอบรถขับ:

Road → Shoulder → Grass → Shoulder → Road

อย่างน้อยบริเวณ Garage City และ Zone 01–03

ตรวจการติดขอบถนน การกระเด้งของรถ และจุดต่างระดับ

ใช้ผลจากการขับจริงประกอบ Geometry Audit

## A5. Boundary

ทดสอบทั้งตัวละครและรถกับขอบโลกจริง

- ไม่มีช่องหลุด
- ไม่ตก Void
- ไม่ชนกำแพงโดยไม่ตั้งใจระหว่างขับบนเส้นทางปกติ
- กล้องไม่ถูกกำแพงบังในจุดเล่น
- ไม่มีปัญหา Collision จากแนวรั้วตกแต่ง

รักษาท้องฟ้าเปิดและแนว Enclosed World B

## A6. UI Regression

ตรวจ:

- Loading ปิดอัตโนมัติเมื่อ Ready จริง
- Loading ไม่แสดงความคืบหน้าปลอม
- Retry ทำงานจริงเมื่อ Timeout
- Welcome เปิดบนแมพจริง
- Welcome Close ได้
- ไม่มี Main Menu หรือปุ่ม Play
- HUD ทำงานหลังปิด Welcome
- Respawn ไม่ทำให้ Popup หรือ HUD ค้าง
- Tutorial อ่านสถานะจริง
- Street Hatch ยังไม่ถูกแสดงเป็นรถพร้อมใช้งาน
- Mobile/Tablet ทดสอบเท่าที่มีเครื่องมือจริง

ถ้าไม่มีอุปกรณ์หรือ Emulator ที่เหมาะสม ให้รายงานว่า Not Tested

## A7. Performance Baseline

วัด FPS, Frame Time, Memory และ Part Count โดยระบุ:

- Studio หรือ Roblox Client
- Edit หรือ Play
- Resolution
- Graphics Settings
- Streaming State
- ระยะเวลาวัด
- ตำแหน่งในแมพ
- สภาพการทำงานของ Studio

เปรียบเทียบก่อนและหลังตกแต่ง

หากยังมีค่าเฉลี่ยใกล้ 15 FPS ให้ตรวจหาสาเหตุและรายงานก่อนเพิ่มรายละเอียดจำนวนมาก

ห้ามอ้างว่าเป็นเพราะ Studio Throttling โดยไม่มีหลักฐาน

**PHASE A GATE:** หาก G3, Full Roundtrip หรือ Cargo ยังไม่ผ่าน ให้หยุดงานที่เสี่ยงกระทบระบบหลัก ส่งรายงานปัญหาและแนวทางแก้ก่อน ไม่ข้ามไปสร้างอาคารสวยเพื่อกลบปัญหา

# PHASE B — GARAGE CITY VISUAL PROTOTYPE

เริ่ม Phase B ได้เมื่อ Phase A ผ่านเกณฑ์หลักและไม่มี Regression ร้ายแรง

## B1. Art Direction

ธีมหลัก:

**THAI STREET GARAGE × ROBLOX STYLIZED 3D × COLORFUL STEAL GAME**

ต้องการความรู้สึก:

- สดใส
- มีชีวิตชีวา
- สีสันสวย
- อ่านรูปทรงง่าย
- เหมาะกับเกม Roblox แนว Steal
- มีกลิ่นอายอู่แต่งรถและเมืองไทย
- ไม่สมจริงจนหม่นหรือมืด
- ไม่เป็นกล่องสีเทาโล่ง ๆ
- ไม่รกจนขับรถยาก

ใช้ภาพที่เจ้าของเกมส่งจาก Studio เป็นหลักฐานสภาพปัจจุบัน ไม่ใช่ภาพอ้างอิงว่าตกแต่งเสร็จแล้ว

## B2. สร้างตัวอย่างอู่เดียวก่อน

เลือก **Garage G1** เป็น Visual Prototype

ห้ามตกแต่งครบ 6 หลังในรอบนี้

G1 ต้องมี:

### ตัวอาคาร
- หลังคาทรงอู่แต่งรถสวยงาม
- กรอบอาคารมีมิติ
- ผนังใช้สีและวัสดุที่เข้าธีม
- ป้ายชื่ออู่เด่น อ่านง่าย
- ปากทางเข้ากว้างพอสำหรับรถ
- รายละเอียดโครงเหล็กหรือคานตกแต่ง
- ไฟหน้าร้านและไฟภายใน

### ภายใน
- พื้นโรงรถที่ดูเป็นพื้นที่ใช้งานจริง
- ช่องจอดรถ
- เส้นกำหนดพื้นที่จอด
- ชั้นวางอะไหล่ตกแต่ง
- โต๊ะช่างหรือเครื่องมือแบบ Non-interactive
- จุดฝาก Cargo เดิมต้องใช้งานได้
- จุด Spawn เดิมต้องใช้งานได้

### ภายนอก
- ลานหน้าอู่สวยงาม
- ทางลาดเรียบ
- ขอบฟุตบาทเฉพาะบริเวณที่ไม่ขวางรถ
- กระถางต้นไม้หรือแนวต้นไม้เล็ก
- ป้ายถนนหรือไฟถนน
- รั้วและสิ่งตกแต่งในตำแหน่งปลอดภัย

ไม่เพิ่ม Prop ที่มี Collision กีดขวางรถ

## B3. แก้หน้าตา Debug Markers

ภาพปัจจุบันมีแผ่นสีฟ้าสดบนพื้นสำหรับจุด Spawn/Interaction

ให้แยกเป็นสองสถานะ:

**Development Mode:** แสดง Marker เพื่อ QA ได้

**Player Mode:** ซ่อน Marker สำหรับนักพัฒนา หรือเปลี่ยนเป็น Visual Marker ที่เหมาะกับเกม โดยไม่ทำให้ระบบ Spawn/Pickup/Deposit เสีย

ห้ามลบ Logic หรือ Attachment ที่ระบบเดิมใช้งาน

## B4. Garage City Ground Treatment

ปรับเฉพาะพื้นที่ตัวอย่าง G1 และบริเวณถนนติดกัน:

- พื้นโรงรถ
- ลานจอด
- ขอบลาน
- ทางเท้า
- พื้นหญ้า
- รอยต่อถนน
- เส้นจราจร

เป้าหมายคือทำให้พื้นและถนนดูเป็นเมืองที่ออกแบบไว้ ไม่ใช่แผ่นสีเทาวางบนสนามหญ้า

ห้ามยกระดับพื้นจนเกิดขอบที่รถติด

## B5. Enclosed World B — Visual Sample

ทำฉากขอบโลกตัวอย่างเฉพาะบริเวณที่มองเห็นจาก G1 และทางเข้า Garage City

ใช้:
- แนวต้นไม้
- เนินเตี้ย
- รั้ว
- อาคารฉากหลัง
- ป้ายหรือองค์ประกอบเมือง

ให้มีหลายชั้นระยะใกล้ กลาง ไกล

ไม่สร้างภูเขาทรงกลมซ้ำ ๆ

ไม่สร้างกำแพงโล่งสูงล้อมเมือง

ท้องฟ้าต้องเปิด

รักษา Boundary Collision เดิมไว้ เว้นแต่พบข้อบกพร่องจริง

## B6. Sky / Lighting / Atmosphere

สร้าง Lighting Preset ตัวอย่าง:

**Bright Thai Garage Day**

ลักษณะ:
- ท้องฟ้าฟ้าสด
- เมฆขาวนุ่ม
- แสงแดดกลางวันอบอุ่นเล็กน้อย
- เงานุ่มพอดี
- สีหญ้าสด
- สีอาคารไม่ซีด
- ผิว Asphalt ไม่ดำสนิท
- ฉากไกลมี Atmospheric Depth เล็กน้อย
- ป้ายและวัตถุอ่านง่าย

ใช้ระบบ Roblox ที่เหมาะสม เช่น Sky, Clouds, Atmosphere, ColorCorrection และ Lighting

Bloom และ SunRays ใช้อย่างพอดี ไม่ให้แสงฟุ้งจนมองถนนยาก

ระวังการใช้ Lighting ระดับโลก เพราะผู้เล่น 6 คนอาจอยู่ต่างโซนพร้อมกัน

ยังไม่ต้องทำระบบเปลี่ยนกลางวัน/กลางคืนหรือแสงเฉพาะ 12 โซน

เก็บค่า Lighting เดิมไว้เพื่อ Rollback

## B7. Performance Budget

ก่อนเพิ่มวัตถุตกแต่ง ให้ประเมินผลกระทบต่อ:

- BaseParts
- Draw Calls เท่าที่เครื่องมือวัดรองรับ
- Transparency
- Dynamic Lights
- Shadows
- Terrain
- Streaming
- Memory

ใช้โมเดลและ Mesh อย่างมีประสิทธิภาพ
